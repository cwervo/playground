# Save to Are.na Chrome Extension

A simple Chrome extension to save selected tabs to your Are.na channels.

## Setup

1.  Clone this repository or download the source code.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable "Developer mode" in the top right corner.
4.  Click "Load unpacked" and select the `Arna` directory.
5.  Click the extension icon in your toolbar to open the popup.
6.  Enter your Are.na API key to log in. You can get one by creating a new application at `https://dev.are.na/oauth/applications`.
7.  Select the tabs you want to save and click "Save Selected Tabs".
8.  Enter the Are.na channel slug (e.g., `my-channel`) when prompted.
