paperwindow · toy edition

Grab a window by the corner and pull.

A desktop where every window is a sheet of paper. Click one to photograph it, then drag its corners until it stretches, creases and catches the light. Let go mid-flick and it wobbles its way flat. This runs the same elastic lattice as the macOS tool it was ported from — only the renderer changed, from Metal triangles to SVG ones.

Same thing, on a real Mac

Photograph

The macOS tool grabs the real window's pixels with ScreenCaptureKit, then slides the original off screen with the Accessibility API so it can't peek out from under a stretched sheet. Here the window is already a drawing, so the toy just reuses its source art.

Simulate

Identical to the Swift version: Verlet velocities, then structural, shear and bend distance constraints relaxed four times a step, plus a soft pull back to the rest shape. That last term is what makes it elastic rather than cloth — it overshoots and rings itself flat.

Light

Each frame every vertex gets its deformation Jacobian. |det J| is the local area ratio, so stretched paper thins and brightens and squashed paper darkens; the dot product of the normalised columns measures shear, which shades the folds.

Draw

Metal maps one texture across a triangle strip. SVG has no mesh primitive, so each triangle instead gets a clip path and an affine matrix that maps its rest corners onto its deformed ones — piecewise texture mapping, done in the DOM.
