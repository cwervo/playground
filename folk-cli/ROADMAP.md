# Folk Computer Installer Roadmap

This document outlines the planned development stages for the Folk CLI installer. Our goal is to start with a core, functional MVP and iteratively add features to improve robustness, usability, and platform support.

| Stage | Features | Key Requirements | Status |
| :--- | :--- | :--- | :--- |
| **1. Foundation (V1 - MVP)** | • Basic Interactive Tcl Installer<br>• OS Detection (macOS & Debian/Ubuntu)<br>• Automated Dependency Installation (`brew`/`apt`)<br>• Git Repository Cloning<br>• Submodule Compilation (`make`)<br>• `folk` CLI Wrapper (`start`/`stop`/`update`/`uninstall`) | • Implement `install.sh` bootstrap<br>• Implement `install.tcl` core logic<br>• Create `folk` command shell script<br>• Fulfill all requirements from `INSTALL-01` to `INSTALL-09` in the PRD. | ⏳ Not Started |
| **2. Robustness & Usability** | • **Idempotent Script:** Can be re-run safely to repair or update an installation.<br>• **Improved Error Handling:** Add detailed logging and more specific error messages.<br>• **Expanded Linux Support:** Add detection and dependency maps for Fedora (`dnf`) and Arch (`pacman`).<br>• **Configuration Prompts:** Ask user if they want to set up for a local or remote tabletop. | • Refactor `install.tcl` to check for existing files/configs before acting.<br>• Add functions for different Linux package managers.<br>• Add interactive prompts for basic configuration choices. | 📝 Planned |
| **3. Advanced Features** | • **Official Homebrew Formula:** Publish a `folk` formula to Homebrew for a native macOS installation experience (`brew install folk`).<br>• **`npx` Wrapper:** Publish a small `npx folk-installer` package to npm for users in the Node.js ecosystem.<br>• **Containerized Setup:** Provide a `Dockerfile` for a fully isolated, one-command development environment (`docker-compose up`). | • Write and submit a Homebrew formula.<br>• Create and publish an npm package that wraps the `install.sh` script.<br>• Write a `Dockerfile` that automates the entire setup process. | 💡 Future |
