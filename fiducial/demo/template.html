Fiducial Optical Bench · visible-light decode

Turn a number into pixels — then read it back.

A number leaves the paper and becomes light: a handwritten digit, a barcode, an AprilTag-style grid, or a subtractive-ink ColorCode. Each panel below encodes a value, then decodes it straight from pixels in your browser and fires alert(value) — the same pipeline a camera runs, minus the camera.

Lineage — Johnny Chung Lee: visible-light & light-sensor fiducials, structured-light tracking (UIST 2004/05; Wiimote projects). This bench extends that idea to a plain 2D camera.

Five real photos of red marker digits on paper. The decoder isolates the red ink, finds the stroke, normalises it to a 32×32 shape, and matches it against an enrolled template dictionary — exactly how a fiducial family is matched to its codebook.

Barcode — bits become bars

A value is written as binary, wrapped in start/stop guard bars and an even-parity bit, then drawn as black & white modules. The decoder sweeps a scan line, measures run widths, and reads the bits back.

AprilTag-style grid — a 2D codebook

A solid black border makes the tag findable and gives four candidate orientations. One inner corner is white — the orientation key — so the decoder can un-rotate the grid before reading the 8 data bits and a 4-bit checksum. Rotate it and it still decodes.

ColorCode — data in subtractive ink

Our technique. Each cell carries three bits, one per ink: Cyan, Magenta, Yellow. Overlapping inks “burn” subtractively — the same maths reads the screen or a photo, because (C,M,Y) = (1−R, 1−G, 1−B).
