Keyboard Shortcuts

  • n Open New Tab
  • f Favorite current site
  • h Access History (disabled in history)
  • c Copy selection (tap again to copy entire page)
  • s Suspend active tab (unload memory)
  • p Save Page as PDF Menu
  • a Previous Tab (wraps)
  • d Next Tab (wraps)
  • D Toggle Dark Mode (Shift+D)
  • l / Focus Omnibar / Select text
  • 1-9 Switch to Tab 1 to 9
  • 0 Switch to Last Tab
  • w Close current active tab (Backspace/Delete also works)
  • Esc Spaces Tab View (closes modals first)
  • Shift Scroll page down 6px
  • Shift+Opt Scroll page up 6px
Shortcuts work only when you are not typing in input fields.
