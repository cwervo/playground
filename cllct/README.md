# Cllct

Cllct is a simple web-based application for managing a collection of items. It allows you to add items, loan them out to others, and track their status.

## Getting Started

To run Cllct, you need a modern web browser and a local web server.

### Development

1.  Clone the repository.
2.  Navigate to the `cllct` directory.
3.  Start a local web server. For example, you can use Python's built-in server:
    ```bash
    python -m http.server
    ```
4.  Open your web browser and go to `http://localhost:8000`.

### Production

For production use, it is recommended to deploy Cllct to a web server with a more robust setup. You can use any static file server, such as Nginx or Apache.
