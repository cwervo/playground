# Party Meditation

This is a simple web app that displays a moving 2D mesh gradient. It's designed to be used as a collective party meditation tool. The app is a Progressive Web App (PWA), so you can install it on your phone and use it offline.

## How to use

1.  Open the `index.html` file in your browser.
2.  The app will display a moving gradient.
3.  You can control the "chaos" of the gradient by moving your phone around.

## How it works

The app uses WebGL to render a fragment shader that generates the 2D mesh gradient. The shader uses a noise function to create the gradient, and the "chaos" of the gradient is controlled by the phone's orientation. The app is a PWA, so you can install it on your phone and use it offline.
